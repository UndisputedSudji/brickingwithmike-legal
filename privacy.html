Data used by the application

The application uses data to provide authorized access, manage LEGO collections, prepare discussion replies and maintain its administrative records.

  • Users: Reddit usernames and application user IDs, roles, permissions and active/disabled status support access control and record ownership. Reddit/Devvit also supplies account and installation context.
  • Inventory: set numbers/names, quantity, purchase price and currency, dates, validation status and optional Owner Notes are stored for the user's collection.
  • Set Watch and Community Watchlist: selected sets, names/aliases and community preferences control the configured scope. Watching a set alone does not enable external collection.
  • Drafts: source title/text, source IDs/links, matched set information and generated or edited reply text are retained for review, along with status and publication references. Configured triggers can generate drafts automatically; publishing requires the owning user's explicit action on an approved draft. Regeneration creates a session preview rather than publishing a comment.
  • Administration: audit events record actors and important changes. Trigger diagnostics and existing server logs can contain source/author identifiers and operational information. These systems are separate from Reddit sentiment Mention storage.

Do not put secrets or unnecessary personal information in Owner Notes, drafts or support messages. Access is controlled by server-side role and ownership checks; authorized administrators have management and export capabilities.

Reddit Sentiment Pilot

The separate sentiment pilot is currently inactive under PENDING policy. If separately activated, it will collect bounded samples of public posts and limited comments about watched LEGO sets from public communities explicitly enabled by an administrator. It stores permitted short-lived title/text snippets, content IDs and permalinks, timestamps, available engagement measurements, set matches and technical provenance. Samples are not a complete archive or a complete view of public interest.

Reddit sentiment Mention storage does not persist structured author identity. Reddit usernames, Reddit user IDs, profile URLs, avatars and flair are not sentiment analytics data. Author identity is not used for Mention identity, deduplication, content fingerprints, content versions, provenance or analytics hooks. Raw text and permalinks may themselves contain names or other identifying information; this is not universal anonymization.

An explicit administrator request for a fresh raw preview can fetch the current post/comment through the Reddit SDK. A username may be displayed transiently when needed for attribution, together with the snippet, Reddit source label and permalink. This attribution is not written back to Mention storage, browser localStorage/sessionStorage, analytics or forecasting. Missing, deleted or inaccessible display data is withheld. A preview expires with its bounded display lease, no later than 30 seconds or the record deadline, whichever is earlier.

There is no author profiling, identity graph, advertising audience creation, Reddit-data sale or licensing, external AI processing of sentiment Mentions, or model training on Reddit sentiment data. Long-term Reddit sentiment aggregates and forecasting using Reddit-derived data are not active production features.

Storage and external services

  • Reddit/Devvit provides hosting, Redis storage, identity/context, content events and supported Reddit API operations. Explicit publication creates a Reddit comment. Reddit's own platform processing is governed separately by Reddit's policies.
  • OpenAI is used for existing Draft generation and regeneration, not the sentiment pilot. Requests to the OpenAI Responses API can include source text/title, set identity, ownership context and owner username, exact Owner Notes, the current draft and limited draft history. This is inference; the application does not operate a model-training pipeline. The applicable provider/account arrangements govern OpenAI's handling of requests. This notice does not promise zero provider retention or that deleting an app record deletes provider copies.
  • Rebrickable receives set lookup requests for validation and catalog details; that lookup does not transmit the user's whole inventory.
  • The Czech National Bank (ČNB) supplies exchange rates. Purchase-price equivalents are derived in the application without sending purchase records to ČNB for conversion.
  • Authorized administrators can prepare and copy bounded business-data exports, including saved Draft source text. Session previews and secrets are excluded. Copies outside the app require separate handling; there is no sentiment Mention export feed.

Server keys are kept in Devvit secret settings. Provider/platform logs and retention are not established solely by this application's code. No particular storage country, certification or zero-retention provider arrangement is asserted here.

Retention and deletion

Reddit sentiment raw Mention records have a fixed deadline no later than 24 hours after the first fetch in a lifecycle. Refresh does not extend the deadline. Content-free deletion markers last 24 hours; a retention anchor can remain for up to 60 seconds beyond the record deadline. A genuinely newer fetch can begin another lifecycle after the guards expire, subject to the active policy. Secondary index and accounting cleanup is bounded and currently operated manually. These limits are not a promise that every platform copy is erased immediately or without maintenance.

PostDelete and CommentDelete handlers remove the corresponding pilot record, provenance and index memberships, with guards against late writes restoring it. Progressive revalidation checks stored items in bounded batches. Temporary provider failure is not treated as confirmed deletion. Administrators can run cleanup or source purge, including while policy is PENDING; purge disables ingestion before removing batches.

A bounded legacy author scrub removes earlier attribution.displayName without changing the record's identity, content version, content or expiry, while keeping indexes and accounting consistent.

Account-deletion event support and cross-community event coverage are not fully established. Removing structured author persistence resolves that specific storage issue, but does not automatically remove identifiers inside raw text/permalinks or in other systems. Short retention and revalidation are not claims of complete Reddit deletion compliance.

Inventory, Users, Set Watch, saved Drafts/source text and publication history have no universal automatic expiry. Audit history is limited to 1,000 entries with a 30-day retention window; trigger diagnostics to 200 entries with a 7-day window. Platform/server-log retention is separate. Removing an app user blocks access and preserves historical business records under the original owner ID; it is not an all-data erasure action. Deleting a Draft does not necessarily delete a published Reddit comment.

Pilot deletion does not automatically remove saved Draft copies, diagnostics, logs, provider records or copied exports. Those copies must be considered separately when handling a request.
